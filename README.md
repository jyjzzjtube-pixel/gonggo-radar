# 공공공고 레이더

LH(한국토지주택공사) · SH(서울주택도시공사) · GH(경기주택도시공사)의
임대 · 분양 · 매각 공고를 하루 3회 자동 수집해, 내 조건에 맞는 순서로 보여주는 PWA.

## 구조

- `collectors.py` — 3사 공개 목록 페이지 파싱 (인증키 불필요, 무료)
- `classify.py` — 제목/구분에서 지역 · 거래유형 · 주택유형 · 자격 · 공고성격 추출
- `build_static.py` — 수집 → `dist/data.json` + 정적 프론트 복사
- `web/` — PWA 프론트 (적합도 계산은 브라우저에서 수행)
- `.github/workflows/collect.yml` — 하루 3회(07/13/19시 KST) 자동 수집 후 Pages 배포
- `server.py`, `store.py` — 갤럭시북 로컬 전용 버전(SQLite + Flask :5095)

## 자동화

GitHub Actions가 수집하고 GitHub Pages가 서빙하므로 **어떤 PC도 켜져 있을 필요가 없다.**
주소는 저장소가 살아있는 한 바뀌지 않는다.

## 개인 조건

희망 지역 · 거래유형 · 자격은 저장소가 아니라 **브라우저 localStorage**에만 저장된다.
저장소에는 공개된 공고 데이터만 들어간다.

## 로컬 실행

```
pip install -r requirements.txt
python build_static.py 3     # 수집 + dist 생성
python server.py             # http://127.0.0.1:5095  (/app/ 은 배포판 미리보기)
```

## 알려진 한계

- SH · GH 목록 페이지에는 마감일 컬럼이 없어 해당 건은 "마감일 미상"으로 표시된다.
  접수기간은 원문에서 확인해야 한다. LH는 목록에 마감일이 있어 D-day가 정확하다.
- 지역 · 자격 분류는 공고 제목 기반 추정이므로 최종 자격 판단은 공고문 원문을 따른다.
- 3사 사이트 구조가 바뀌면 수집이 0건이 될 수 있다. 이 경우 빌드가 실패하도록 해
  낡은 데이터가 조용히 배포되는 것을 막는다.
